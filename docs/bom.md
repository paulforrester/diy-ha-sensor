## 1. Summary

**The run:** 10 identical standard units, plus spares. Each unit has:

- the option B design approved on PR #1:
  - XIAO ESP32-C3;
  - LD2412 radar;
  - genuine SHT45;
  - OPT3001 lux sensor;
  - the two-part case with the separate climate pod;
- a CO2 sensor as standard, so every unit is interchangeable (Paul's decision);
- a 1-Wire socket for optional remote temperature probes (DS18B20), so probes can be added later without changing
  the unit (Paul's decision; section 5);
- its own USB wall adapter and a white 2 m USB-A to USB-C cable.

Against the snippet estimate (€868-1,125), the low end rose by about €150 and the high end by about €70 [calc]:

- **USB adapters, about +€75:** the €2.50 adapter in the draft is an unbranded 1 A part that fails this BOM's own
  "reputable brand" rule. Branded ones on Amazon.fr cost €10-12 each (line 11). Paul decides; see section 3.
- **OPT3001 boards, about +€28, and radars, about +€21:** real listings cost more than the snippets suggested.
- **Everything from DigiKey** is within a few cents of the snippet figures.

**Why the CO2 sensor costs more than the brief's estimate.** The brief estimated €20-25 per CO2 sensor.

- That price only exists for unbranded marketplace SCD40 boards, which carry a real counterfeit and refurbished risk.
- Apollo's €23.99 SCD40 module doesn't fit this design. It plugs into a proprietary mezzanine connector on Apollo's
  board (Apollo docs, "Adding CO2 to MSR-2").

If the cost matters, the one large saving left is unbranded SCD40 boards, at about €10-25 each [S]. They would be
checked on arrival using the variant and serial commands and an outdoor reading near 420 ppm. I don't recommend it for
a run whose point is accurate, interchangeable units.

## 2. What changed since the proposal

- **Quantities:** a run of 10, not 4. Some units may go to the US; only the USB wall adapter differs (section 6).
- **CO2 is standard on every unit** (Paul, 2026-10-15).
  - The proposal's cheapest genuine option, the Apollo module, is out (connector, above), so the Adafruit SCD-40 is
    the primary.
  - Adafruit's board has a 3.3 V regulator and level shifters, and runs from 3.3 to 5 V (Adafruit-SCD-4x-PCB README
    on GitHub).
  - It is wired to the XIAO's 3V3 by default. The I2C pull-ups follow the board's supply, so feeding it 5 V could put
    5 V on the ESP32's I2C pins.
  - Phase 2 checks Adafruit's schematic, and checks the XIAO's 3.3 V regulator headroom. The XIAO wiki states both
    500 mA and 700 mA [G]. The ESP32-C3 Wi-Fi peak (350 mA) plus the SCD40 peak (175 mA) is about 525 mA [D] [A].
- **No separate cellar design.** The cellar gets a standard unit like every other room.
- **1-Wire socket on every unit** (Paul, 2026-10-15). It costs well under €1 per unit [A], and it keeps the units
  interchangeable while leaving room for remote temperature probes later (section 5).
- **USB supply and cable:** one each per unit (Paul's answer). A USB-A supply with an A-to-C cable avoids USB-C power
  negotiation questions entirely.

## 5. The 1-Wire socket and future probes

Every unit gets a socket for DS18B20 temperature probes on a cable. These are for readings away from the unit: wine or
bottle temperature in the cellar, floor versus ceiling, several racks. No probes are bought now.

- **On the unit:**
  - XIAO **D2 / GPIO4**, a free pin that is not a strapping pin (ESPHome's C3 strapping pins are GPIO2, 8 and 9);
  - a **4.7 kΩ pull-up to 3V3**;
  - a **JST-XH 3-pin header** inside the main body;
  - a cable knock-out in the case (Phase 3).
- **Firmware:** an optional ESPHome package (`one_wire` with the `gpio` platform, plus `dallas_temp`; both in
  2026.9.1), off by default (Phase 2).
- **Adding a probe later:**
  - Buy **genuine DS18B20+ chips from an authorised distributor** (DigiKey, Mouser, Farnell, RS) and build the probe:
    3-core cable, adhesive-lined heat shrink, optionally a stainless sleeve, and a pre-crimped XH 3-pin pigtail.
    Marketplace probes are not an option: a 2019 study bought DS18B20s from over 70 vendors, and every probe from eBay
    and AliExpress contained a counterfeit chip (github.com/cpetrich/counterfeit_DS18B20).
  - On first boot, check each probe's ROM code in the ESPHome log against the genuine pattern `28-xx-xx-xx-xx-00-00-xx`
    from the same study.
- **Open for bring-up:** how long a cable the 4.7 kΩ pull-up handles reliably is not established here. It is checked
  when the first probe is added [A].

## 8. Live price pass

**Done on 2026-10-15** for lines 1-14 by a Claude Code session on Paul's Mac (branch `bom-live-prices`). Every shop
page opened:

- DigiKey.fr, Gotronic, Berrybase and Domadoo;

The draft's gaps are filled: the OPT3001 board, the JST-SH cables, the JST-XH part number, the white 2 m cables and
the SCD-40's DigiKey URL. Section 3 has the results. Stock and marketplace prices move, so repeat the pass with these
steps if the order is placed more than a few days later:

1. **Check out the branch.** Work on this PR's branch, and check that the PR isn't merged yet.
2. **Price each line.** For each line in `docs/bom.csv`, open the primary and alternative product pages. Record in
   that row:
   - the price including VAT, delivered to France;
   - the exact product URL;
   - stock;
   - shipping cost or free-delivery threshold;
   - delivery estimate.
3. **Label the prices.**
   - Set `price_status` to `live-checked YYYY-MM-DD`, and `date_checked` to the date.
   - Keep `eur_low` / `eur_high` as the cheapest and dearest credible offers.
   - If a page can't be read (JavaScript-only or bot-blocked pages are common on AliExpress, Amazon, DigiKey and
     Mouser), leave the line `estimated` and say so in `notes`. Never record a guess as live.
4. **Check the choices still hold.** On AliExpress, select the right variant before reading the price (the listings
   open on a different model). Raise the quantity to the run quantity to see seller shipping, which scales with
   quantity.
5. **Regenerate.** Re-run `python3 tools/bom_totals.py` and check that the tables in sections 3 and 4 changed as
   expected.
6. **Commit.** Commit with a message that lists which lines were live-checked, and push to the same branch.
7. **Final check by Paul.** The cart is the only exact figure for delivery, VAT and duty, so Paul checks it before
   paying.
