## 1. Summary

**The run:** 10 identical standard units, plus spares. Each unit has:

- the option B design approved on PR #1:
  - XIAO ESP32-C3;
  - LD2412 radar;
  - genuine SHT45;
  - OPT3001 lux sensor;
  - the two-part case with the separate climate pod;
- a CO2 sensor as standard, so every unit is interchangeable (Paul's decision);
- its own USB wall adapter and cable.

**Estimated cost:**

| | Estimate |
|---|---|
| Standard unit, per unit | about €72-85 |
| ...of which the CO2 sensor (genuine Adafruit SCD-40) | about €48-54 |
| USB adapter and cable, per unit | about €4.50-10 |
| **Whole run**, before delivery and duty | **about €870-1,120** |

**Why the CO2 sensor costs more than the brief's estimate.** The brief estimated €20-25 per CO2 sensor.

- That price only exists for unbranded marketplace SCD40 boards, which carry a real counterfeit and refurbished risk.
- Apollo's €23.99 SCD40 module doesn't fit this design. It plugs into a proprietary mezzanine connector on Apollo's
  board (Apollo docs, "Adding CO2 to MSR-2").

If the cost matters, the one large saving left is unbranded SCD40 boards, at about €10-25 each [S]. They would be
checked on arrival using the variant and serial commands and an outdoor reading near 420 ppm. I don't recommend it for
a run whose point is accurate, interchangeable units.

## 2. What changed since the proposal

- **Quantities:** a run of 10, not 4. Some units may go to the US; only the USB wall adapter differs (section 5).
- **CO2 is standard on every unit** (Paul, 2026-10-15).
  - The proposal's cheapest genuine option, the Apollo module, is out (connector, above), so the Adafruit SCD-40 is
    the primary.
  - Adafruit's board has a 3.3 V regulator and level shifters, and runs from 3.3 to 5 V (Adafruit-SCD-4x-PCB README
    on GitHub).
  - It is wired to the XIAO's 3V3 by default. The I2C pull-ups follow the board's supply, so feeding it 5 V could put
    5 V on the ESP32's I2C pins.
  - Phase 2 checks Adafruit's schematic, and checks the XIAO's 3.3 V regulator headroom. The XIAO wiki states both
    500 mA and 700 mA [G]. The ESP32-C3 Wi-Fi peak (350 mA) plus the SCD40 peak (175 mA) is about 525 mA [D] [A].
- **No separate cellar design.** The cellar gets a standard unit like every other room.
- **USB supply and cable:** one each per unit (Paul's answer). A USB-A supply with an A-to-C cable avoids USB-C power
  negotiation questions entirely.

Not included above:

- **Delivery:**
  - DigiKey.fr: free from €50 (some pages say €75). Below that, €18-25.
  - AliExpress "Choice": free from €10 to France.
  - Amazon.fr: depends on the seller.
- **EU customs duty:** news reports say a flat €3 per goods category on parcels under €150 from outside the EU, since
  2026-07-01, plus a handling fee from 2026-11-01 whose amount isn't set [S, unverified]. Expect about €6-12 on the
  AliExpress order.
- **VAT:** DigiKey and Mouser list prices ex-VAT. The snippet figures here add 20 %; check the cart, which should show
  DDP (duties paid).
